  pl: |
    Strona ma wizytówkę dla rekruterów, listę projektów i publiczny Dev Log. Pięć kart pokazuje bieżącą pracę, aktywność na GitHubie, czas z WakaTime, eksperymenty i muzykę z Last.fm. Wszystkie widoki dzielą jeden system wizualny: tokeny, kafle, typografię i jeden czerwony akcent.

    Strony są statyczne (Astro), a dane dociągają małe wyspy w czystym TypeScripcie z własnych endpointów /api/*. Serwer Node działa na Cloud Run za Cloudflare i skaluje się do zera; klucze API zostają po stronie serwera. Kafle z danymi mają cztery stany: ładowanie, dane, nieaktualne i błąd. Zajawka na wizytówce nadal pokazuje czas, pogodę i muzykę, a terminal zachowuje pozostałe integracje.

    Homelab nie jest wystawiony do internetu — agent na Raspberry Pi sam wysyła co minutę zanonimizowane statystyki do API tej strony i Firestore. Prywatny dashboard za hasłem służy do obsługi usług, historii serwera, backupów, deployów i pozostałych danych operacyjnych. Istniejące publiczne API statystyk pozostają dostępne, ale Dev Log nie wyświetla telemetrii homelabu. Galeria zawiera historyczne zrzuty poprzedniego układu.
  en: |
    The site has a profile for recruiters, a project list and a public Dev Log. Five cards show current work, GitHub activity, WakaTime totals, experiments and Last.fm music. All views share one visual system: tokens, tiles, typography and a single red accent.

    Pages are static (Astro); small islands in plain TypeScript fetch the data from the site's own /api/* endpoints. The Node server runs on Cloud Run behind Cloudflare and scales to zero; API keys stay on the server. Live tiles have four states: loading, data, stale and error. The home teaser still shows time, weather and music, while the terminal retains the other integrations.

    The homelab is not exposed to the internet — an agent on a Raspberry Pi pushes anonymised stats every minute to this site's APIs and Firestore. A password-protected private dashboard handles services, server history, backups, deploys and other operational data. Existing public stats APIs remain available, while Dev Log displays no homelab telemetry. The gallery contains historical screenshots of the previous layout.
