description:
  pl: |
    Domowy serwer na Raspberry Pi, na którym w kontenerach Dockera działają usługi: multimedia, pliki, DNS z blokadą reklam (AdGuard Home), monitoring (Uptime Kuma) i kopie zapasowe (restic). Ruch do usług idzie przez Caddy, a dostęp z zewnątrz jest tylko przez Tailscale — żaden port nie jest otwarty do internetu.

    Cała konfiguracja jest w repozytorium razem z instrukcją odbudowy, więc serwer da się postawić od zera na nowej karcie. Własny agent co minutę zbiera zużycie maszyny, stan usług, transfer i statystyki DNS i wysyła je do API tej strony i Firestore — bez nazw hostów i adresów. Prywatny dashboard służy do obsługi serwera, a publiczny Dev Log zawiera tylko notatkę o eksperymencie i link do tego opisu. Dotychczasowe publiczne endpointy statystyk pozostają dostępne; Dev Log nie jest demonstracją telemetrii.
  en: |
    A home server on a Raspberry Pi running services in Docker containers: media, files, ad-blocking DNS (AdGuard Home), monitoring (Uptime Kuma) and backups (restic). Traffic to the services goes through Caddy, and access from outside is only over Tailscale — no port is open to the internet.

    The whole configuration lives in a repo with rebuild instructions, so the server can be set up from scratch on a fresh card. My own agent collects machine usage, service status, traffic and DNS stats every minute and pushes them to this site's APIs and Firestore — without host names or addresses. The private dashboard handles server operations; the public Dev Log contains an experiment note linking to this description. Existing public stats endpoints remain available; Dev Log is no longer a telemetry demo.
